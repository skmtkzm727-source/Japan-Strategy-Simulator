# Simutransコード利用方針

## 現時点

このリポジトリの現行プロトタイプに、Simutrans本体のソースコードやPakset、画像、音源などの素材は取り込んでいません。輸送・物流のゲームデザインを参考にした独自実装です。

## 参照先

- Source repository: https://github.com/simutrans/simutrans
- License file: https://github.com/simutrans/simutrans/blob/master/LICENSE.txt

Simutrans本体はArtistic License 1.0で公開されています。これはMIT Licenseではありません。採用対象のファイル・バージョン・著作権表示・改変点を確認せずに、コードをコピー・再配布しないでください。Paksetや追加素材は本体ソースと別ライセンスの場合があるため、個別に確認します。

## 採用前チェックリスト

1. 取り込むファイルと使用する関数を限定する。
2. 対象バージョンのLICENSE.txtおよび当該ファイルの著作権表示を確認する。
3. Artistic License 1.0の原文に照らして、改変版の公開・配布形態が条件に適合するか確認する。
4. 由来ファイル、改変日、変更者、改変内容を記録する。
5. 配布物に必要なライセンス文書・著作権表示・ソース提供方法を含める。
6. Pakset、画像、音源、フォント、マップデータの権利は別途確認する。
7. 商用化・有料配布の前に、ライセンス条件を専門家または権利者に確認する。

## 実装方針

ブラウザ側の描画/UIは本プロジェクトで独立して実装します。Simutransコードを直接利用する必要性が明らかになった段階で、経路探索、貨物ルーティングなど処理単位ごとに候補を評価します。コードの移植が必要な場合は、移植元と改変履歴を追跡できるようにします。
